# Abu Hasif Portfolio

Professional portfolio for Abu Hasif Bin Abu Bakar, built with React, TypeScript,
Vite, and Tailwind CSS.

## Highlights

- Responsive portfolio layout with mobile navigation.
- Interactive project filters and expandable project details.
- Accessible buttons, focus states, and valid external links.
- Portfolio-specific metadata and downloadable resume link.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
