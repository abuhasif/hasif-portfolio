# Project Visuals

Add project screenshots or preview images in this folder.

The portfolio data already references these filenames:

- `portfolio-dashboard.webp`
- `mrt-infographic-generator.webp`
- `geometry-collision-toolbox.webp`

`Unarmed` intentionally uses the YouTube trailer embed instead of a screenshot.

Recommended size: 1600 x 1000 or 1440 x 900.

Use `.webp` for best performance. If you use another extension, update the
matching `image` path in `src/data/projects.ts`.
